Portable English Windows release of Meeting Capture.

- Paste an output folder, including a quoted Windows path, and select a fixed capture region.
- Save repeated PNG screenshots using the floating toolbar, without taking focus away from a presentation.
- Timestamp-and-sequence filenames preserve existing files and contain no meeting-name prefix.
- Supports secondary monitors and mixed display scaling; includes protection against double-clicks reaching the slide underneath.

Download and extract the Windows x64 ZIP, then run `MeetingCapture.exe`. No installer, Python, or Office is required. The standalone EXE is also provided. `SHA256SUMS.txt` contains hashes for both assets.

Uses Windows' built-in .NET Framework desktop components. Interactive checks were performed on Windows 11; an independent Windows 10 machine and clean-machine compatibility have not been verified. See the README for the tested scope.
