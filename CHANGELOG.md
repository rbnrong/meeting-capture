# Changelog

Versions follow Semantic Versioning. This file records user-visible changes.

## 1.1.0 - 2026-11-11

First public English release, based on the local Windows utility.

- English setup window, region selector, toolbar, messages, and documentation.
- Direct folder input and paste support, including surrounding straight or smart quotes.
- Timestamp-and-sequence PNG filenames without a meeting-name prefix.
- Single-EXE distribution, mixed-DPI support, and fixed-region capture.
- Toolbar hiding, foreground preservation, and protection against double-clicks reaching the presentation.
- Windows build and release workflows with portable ZIPs and SHA-256 checksums.
